# Генератор этикеток из PDF (2D-коды)

Десктопная утилита на Python для пакетной нарезки 2D-кодов из многостраничных PDF-документов и формирования готовых этикеток заданного формата с автоматической нумерацией.

**Зачем создана:** если Вам пришлось заказывать коды маркировки в системе «Честный знак», но стандартный формат этикеток не подходит (или вы забыли выбрать нужный шаблон при выгрузке), эта утилита поможет не тратить бюджет на повторный заказ. С её помощью можно вырезать 2D-коды и распечатать их на популярном размере этикеток **40 × 25 мм**. Для удобного контроля печати справа добавляется вертикальная нумерация, соответствующая номеру страницы исходного файла.

## Основные возможности

- **Интерактивное выделение области:** Визуальный выбор границ 2D-кода на первой странице каждого документа с сохранением векторного качества при масштабировании.
- **Пакетная обработка:** Последовательная обработка всех PDF-файлов из входной директории с индивидуальной настройкой области вырезки для каждого файла.
- **Автоматическая верстка этикетки:**
  - Формат страницы: **40 × 25 мм**.
  - Отступы для 2D-кода: **8 мм** слева, по **4 мм** сверху и снизу.
  - Вертикальная нумерация страниц (от 1 до 999) с отступом **7 мм** от правого края.
- **Автоматическая сортировка файлов:** Сохранение готовых этикеток в выходную директорию и архивация обработанных исходников.

---

## Структура директорий

При первом запуске программа автоматически создает необходимую файловую структуру в корневой папке скрипта или `.exe` файла:

```text
├── main.py            # Исполняемый файл программы (или LabelGenerator.exe)
├── version_info.txt   # Метаданные версии и авторских прав для сборки .exe
├── IN/                # Папка для исходных PDF-файлов
│   └── Done/          # Архив успешно обработанных исходников
└── OUT/               # Готовые файлы с этикетками (*_labels.pdf)
```

---

## Требования и запуск из исходного кода

Для работы требуется **Python 3.8+** и библиотека **PyMuPDF** (модуль `tkinter` входит в стандартную поставку Python).

1. Установите зависимость:
   ```bash
   pip install pymupdf
   ```
2. Поместите исходные PDF-файлы в папку `IN`.
3. Запустите скрипт:
   ```bash
   python main.py
   ```

---

## Сборка автономного `.exe` файла (Windows)

Чтобы запускать программу на компьютерах без установленного Python, её можно упаковать в один исполняемый файл с помощью утилиты **PyInstaller**.

1. Установите PyInstaller:
   ```bash
   pip install pyinstaller
   ```
2. Выполните команду сборки в папке с файлом `main.py`:

   ```bash
   pyinstaller --onefile --noconsole --version-file=version_info.txt --name "Pdf2DLabelReformat" main.py
   ```

   - `--onefile` — собирает программу и все библиотеки в один `.exe` файл.
   - `--noconsole` — отключает появление черного окна консоли при запуске графического интерфейса.
   - `--version-file` — вшивает информацию об авторе и версии из `version_info.txt` в свойства `.exe` файла.
   - `--name` — задает имя итогового файла (`LabelGenerator.exe`).

3. Готовый файл появится в папке `dist/`. Перенесите его в рабочую директорию — при первом запуске он сам создаст папки `IN`, `OUT` и `IN/Done` рядом с собой.

## Порядок работы

1. **Запуск и проверка очереди:** Программа сканирует папку `IN`. Если обнаружено более одного PDF-файла, запрашивается подтверждение на запуск пакетной обработки.
2. **Выбор области кода:** Для каждого файла открывается окно предпросмотра первой страницы:
   - **Выделить область:** Зажмите левую кнопку мыши, обведите 2D-код и отпустите кнопку — файл сразу отправится в обработку.
   - **Пропустить файл:** Закройте окно крестиком (исходный файл останется в `IN`).
   - **Прервать очередь:** Нажмите кнопку **«Отменить всё»**, чтобы остановить обработку оставшихся файлов.
3. **Завершение:** Готовые файлы сохраняются в `OUT` с суффиксом `_labels.pdf`, исходники переносятся в `IN/Done`, а на экран выводится итоговая сводка.

---

## Ограничения

- Максимальное количество страниц в одном обрабатываемом PDF-файле — **999 страниц**. При превышении лимита файл пропускается с выводом предупреждения (система «Честный знак» на момент написания программы выгружала не более 500 этикеток в одном файле).
- При наличии одноименного файла в папке `IN/Done` он будет перезаписан новой версией.
